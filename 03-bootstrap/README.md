# Module 3: Bootstrap

Bootstrap is a pre-built, component-based CSS framework: instead of writing every style
rule yourself, you assemble pages out of ready-made grid columns, buttons, cards, navbars,
and forms. This module goes from the grid system to fully customizing Bootstrap's theme.

**Difficulty range:** Beginner → Intermediate+
**Prerequisites:** [Module 1: HTML](../01-html/), [Module 2: CSS](../02-css/)

## How to Run These Demos

Bootstrap is loaded from a CDN (`cdn.jsdelivr.net`) in every demo's `index.html`, so you
just need to open the file in your browser — **an internet connection is required** to
load Bootstrap's CSS and JS, but nothing needs to be installed. Topic 3.5 (customizing the
theme via Sass) is the one exception and explains its own setup in its README.
