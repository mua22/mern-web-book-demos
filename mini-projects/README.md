# Mini Projects

The numbered modules ([01-html](../01-html/) through [07-jquery](../07-jquery/) and
onward) teach one topic at a time in isolation. Mini projects are the opposite: small,
complete, realistic builds that combine several topics at once, the way you actually use
them in practice. Each one lives in its own folder, is fully self-contained, and has a
README explaining not just what it does but *why* it's built the way it is.

Mini projects are ordered roughly by how many modules' worth of skills they combine, not
by a strict prerequisite chain - check each project's own README for exactly what it
draws on.

## How to Run These Projects

Every project's own README has exact run instructions, but the short version: most need
nothing but a browser (open `index.html` directly), and any project with extra
requirements (a CDN, a build step) says so clearly at the top of its README.
