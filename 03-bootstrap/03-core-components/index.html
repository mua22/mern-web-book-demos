Bootstrap Core Components

This page combines a navbar, buttons, alerts, a row of cards, and a modal window into a single small demo.

Buttons

Modal

A modal is a dialog window that appears above the page. It requires Bootstrap's JavaScript bundle to open and close, which this page loads at the bottom of <body>.

Demo Modal

This window is a Bootstrap modal. It is opened by a button with data-bs-toggle="modal" and data-bs-target pointing at this modal's id, and closed by the button below or the close icon above.
