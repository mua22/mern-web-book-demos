The Box Model

Every element on a page is a rectangular box made of four layers: content, padding, border, and margin. Resize your browser or just look closely at the colors below to see each layer.

1. One Box, Four Layers

content

Yellow = padding, blue border = border, the dashed outline shows where the margin ends.

2. content-box vs. border-box

Both boxes below have width: 300px and the same padding and border. Only box-sizing is different.

box-sizing: content-box

Total rendered width is bigger than 300px, because padding and border are added on top of the content width.

box-sizing: border-box

Total rendered width stays exactly 300px, because padding and border are squeezed inside that width.

3. Margin Collapsing

Each box below has margin: 30px on top and bottom. You might expect 60px of gap between them (30 + 30), but vertical margins between siblings collapse into a single margin: the gap is only 30px.
