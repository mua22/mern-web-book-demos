Absolute vs. Relative Links

An absolute link includes the full address, protocol and all, such as https://developer.mozilla.org/. It works no matter where the linking page is located, but it always points to one specific external destination.

A relative link only describes the path from the current page to another file, without repeating the protocol or domain. The link to page2.html further down this page is a relative link: it just says "look for a file named page2.html in this same folder." Relative links are what you use for links between pages within your own site or project.

Opening Links in a New Tab

Adding target="_blank" to a link makes it open in a new browser tab instead of replacing the current page. For example: open MDN in a new tab.

When you use target="_blank", you should also add rel="noopener". Without it, the new page you just opened can, in some browsers, get partial access to the original page's window object through JavaScript, which is a small but real security risk (sometimes called "tabnabbing"). Adding rel="noopener" blocks that access, so it's considered best practice to always pair the two together.

Email and Phone Links

A mailto: link opens the visitor's default email app with a new message already addressed to the given email: Email us.

A tel: link, when opened on a phone (or a computer with calling software set up), starts dialing the given number: Call us.
