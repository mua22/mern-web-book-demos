Responsive Cards

These three cards sit side by side on a wide screen. Resize your browser window narrower than 768px, or open your browser's device toolbar, and they will stack into a single column instead.

Card One

This card is sized with fluid units, so it grows and shrinks smoothly with the screen instead of jumping around.

Card Two

Below the 768px breakpoint, a media query switches the container from a row to a column, so each card takes the full width.

Card Three

This approach - Flexbox plus a media query - is one of the most common patterns you will use for responsive layouts.
