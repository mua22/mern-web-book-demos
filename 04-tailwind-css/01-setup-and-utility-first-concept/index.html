Utility-First Concept

Every visual style on this page (spacing, color, text, rounded corners) comes from classes written directly on the HTML elements below. There is no separate CSS file linked in this page's <head>.

Hello, Tailwind!

The box above is built with exactly five utility classes on one <div>:

  • p-4 - padding on all four sides
  • bg-blue-500 - a medium blue background color
  • text-white - white text color
  • rounded - slightly rounded corners
  • font-bold - bold font weight

A second box, same idea

This one uses bg-slate-100 instead of bg-blue-500, and has no text-white, so the default dark text color shows through.
