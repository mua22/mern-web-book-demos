5.1: Embedding Scripts and the Browser

This page loads its JavaScript from a separate file, script.js, using <script src="script.js" defer></script> in the <head> above. Open your browser's DevTools Console (see README.md for how) to see the messages script.js logs there.

This text was written directly in index.html and has not been touched by JavaScript yet.

If script.js ran successfully, the box above should now say something different - proof that an externally linked, deferred script can find and change an element that appears later in the HTML file.
