About This Demo

You made it here by clicking a link in index.html. Nothing complicated happened behind the scenes: the browser read the href attribute on that link, figured out the address it pointed to, and loaded this file instead.

If this page were hosted on a real web server instead of sitting on your hard drive, that same click would trigger an HTTP request over the network to the server, and the server would send back an HTTP response (usually with status code 200, meaning "OK, here is the page you asked for"). That request/response exchange is exactly what shows up in the Network tab of DevTools on a real hosted site.
