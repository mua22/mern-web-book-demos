Images and Media Demo

This page demonstrates images and media in HTML: the img tag, the figure/figcaption pair, and the audio and video tags.

The img Tag

Label: a plain img tag, pointing at image.svg, a small hand-made icon file sitting in this same folder. This works completely offline, since the image is a local file, not something loaded from the internet.

The src attribute points to the image file. The alt attribute provides a text description of the image, used by screen readers and shown if the image fails to load; it should always be included and should describe the image's content or purpose. The width and height attributes tell the browser the image's display size in pixels ahead of time, which helps the page lay out correctly without jumping around as images load.

figure and figcaption

Label: the box below uses figure to group an image together with its caption (figcaption). This is the correct way to show an image alongside a caption that describes it, such as in an article or a gallery.

The audio Tag

Label: below is an audio element with the controls attribute, which adds a visible play/pause/volume bar. This example loads a short public sample sound file from MDN (Mozilla's developer documentation site), so it needs an internet connection to play; every other part of this page works fully offline.
