Bootstrap Setup and the Grid System

This page loads Bootstrap from a CDN and uses only two things: the container class and the 12-column grid (row / col).

Container vs. Container-Fluid

This whole page is wrapped in a single .container, which centers the content and adds a comfortable side margin that adjusts at each breakpoint. Below, a .container-fluid is shown instead, which always stretches to the full width of the browser window.

This box uses .container-fluid, so it spans the full width of the viewport instead of stopping at a fixed max-width.

The 12-Column Grid

Bootstrap divides horizontal space into 12 equal columns. Every row is a wrapper, and every direct child col-* inside it takes up some number of those 12 columns. Three columns that each take up 4 out of 12 columns fill the row exactly (4 + 4 + 4 = 12).

Responsive Columns: 3 Columns to 1

The row below uses col-12 col-md-4 on each column. On screens narrower than the md breakpoint (under 768px), each column is col-12, meaning it takes the full row width, so the three boxes stack vertically. At md and wider, each becomes col-4, so they sit side by side. Resize your browser window (or open the page on a phone) to see this happen.

Feature Two

Feature Three

Uneven Columns

Columns in a row do not have to be equal. As long as the numbers in one row add up to 12 or less, you can mix sizes, such as a wide column next to a narrow one.
