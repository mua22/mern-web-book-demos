Display & Positioning

1. The display Property

display: block

Block elements stack vertically and take up the full width available.

Block A Block B

display: inline

Inline elements sit in the flow of text and only take up as much width as their content.

Inline A Inline B Inline C

display: inline-block

Inline-block elements sit side by side like inline, but accept width, height, and vertical margin/padding like block.

Box A Box B

display: none

The box below has display: none. It is completely removed from the page -- not just invisible, but taking up no space at all.

2. The position Property

static: follows normal document flow. top/left/right/bottom do nothing here.

position: relative

relative, shifted with top/left: still takes up its original space, then shifts visually.
