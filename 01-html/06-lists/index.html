Lists in HTML

Unordered List: Grocery List

Use <ul> (unordered list) when the order of the items does not matter. Each item goes inside its own <li> (list item).

  • Milk
  • Eggs
  • Bread
  • Rice
  • Bananas

Ordered List: Recipe Steps

Use <ol> (ordered list) when the sequence matters, like steps in a recipe. The browser numbers the items automatically.

  1. Boil water in a pot.
  2. Add pasta and cook for 10 minutes.
  3. Drain the pasta.
  4. Add sauce and stir.
  5. Serve hot.

Nested List: Grocery List by Category

Lists can be nested by placing a whole <ul> or <ol> inside an <li> of another list. This is useful for grouping items, like organizing groceries by category.

  • Dairy
    • Milk
    • Cheese
    • Yogurt
  • Produce
    • Bananas
    • Spinach
    • Tomatoes
  • Bakery
    • Bread
    • Bagels

Description List: Small HTML Glossary

Use <dl> (description list) to pair terms with their definitions. Each term goes in a <dt> (description term) and each definition goes in a <dd> (description detail) right after it.

HTML
HyperText Markup Language. The language used to describe the structure of a web page.
Tag
A piece of markup like <p> that tells the browser what a piece of content is.
Element
A tag together with its content and closing tag, for example a whole <p>...</p> block.
Attribute
Extra information added inside an opening tag, such as href in a link.
