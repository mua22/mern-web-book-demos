A Custom Bootstrap Theme

This page links dist/custom.css, a locally built Bootstrap stylesheet compiled from custom.scss with overridden Sass variables. It uses ordinary Bootstrap classes, but the colors and rounded corners you see below are not Bootstrap's defaults.

Buttons

These buttons use the plain btn btn-primary classes, exactly like in Topic 3.3. Because $primary was overridden to a purple before Bootstrap compiled, and $border-radius was made larger, every "primary" element and every rounded element automatically reflects the new theme with no extra classes.

Card

Themed Card

The card's corners use Bootstrap's $border-radius variable, which was overridden in custom.scss, so this card is noticeably more rounded than the default Bootstrap card.

Alert

This is a alert-primary box. Its background tint is generated from the same overridden $primary variable used by the buttons above.
