jQuery vs. Modern JavaScript

Both buttons below do the exact same thing - open and close the panel underneath them - but one is wired up with jQuery, and the other with plain ("vanilla") modern JavaScript, with no library at all.

jQuery

This panel is toggled using jQuery's $('#panel-jquery').toggleClass('open').

Vanilla JavaScript

This panel is toggled using plain JavaScript's document.getElementById('panel-vanilla').classList.toggle('open').

Neither panel has been toggled yet.
