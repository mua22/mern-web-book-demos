Spacing Utilities

Spacing classes follow the pattern {property}{sides}-{size}, for example m-3 (margin, all sides, size 3) or pt-4 (padding-top, size 4). Sizes run from 0 to 5.

m-1 p-1
m-3 p-3
p-5 m-1

Directional variants target one side: mt-* (margin-top), mb-* (margin-bottom), ms-* (margin-start, i.e. left in English), me-* (margin-end, i.e. right), and mx-* / my-* for both horizontal or both vertical sides. The same pattern applies to padding (pt-*, pb-*, ps-*, pe-*, px-*, py-*).

mt-3 ms-4

Spacing classes can also be prefixed with a breakpoint, e.g. mt-md-5 applies mt-5 only at the md breakpoint and above.

mt-2 mt-md-5 (grows on wider screens)
