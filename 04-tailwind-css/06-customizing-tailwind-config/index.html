Custom Theme

Every class on this page is compiled by the Tailwind CLI from tailwind.config.js and input.css into dist/output.css, which is the only stylesheet this page links to. There is no CDN script on this page at all.

bg-brand + p-18

The background color here comes from the custom brand color (#6d28d9) added under theme.extend.colors in tailwind.config.js. The padding uses a custom spacing value, p-18 (4.5rem), also added under theme.extend.spacing.

Ordinary, built-in Tailwind utilities still work exactly as before — this box uses stock classes only: border, rounded-lg, p-6, bg-white.

This line uses text-brand, the same custom color as a text color instead of a background.
