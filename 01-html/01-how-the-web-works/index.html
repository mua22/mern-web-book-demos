How the Web Works

This is a plain HTML page. Right now, your browser loaded it from your own computer's hard drive, using a file:// address. You can check this by looking at the address bar at the top of your browser.

Below is a link to another page in this same folder, about.html. Before you click it, open your browser's DevTools and switch to the "Network" tab (see the README in this folder for exact steps). Then click the link and watch what does, and does not, show up.

Go to the About page

That link's href value, about.html, is a URL. A URL (Uniform Resource Locator) is simply an address that tells the browser which resource to fetch and where to find it. When you clicked it, the browser worked out the full address (a file:// path on your machine) and loaded that file.
